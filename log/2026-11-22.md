## Скилл `reaper-song`: старый проект без цепочек → под шаблон

Источник - «Tap Up - Чтобы любить - 32bit» (31.05.2025, перенесена с popstas-pc). На треках только ReaVerb на шинах папок, на мастере ReaComp и ReaLimit. Модель их не считает: она дала −11.1 LUFS, рендер «до» вышел −11.9 LUFS при true peak +0.2 dBTP.

- **`chain.py`** (новый): переносит звенья из шаблона `guitar and mic` в старый `.rpp` без изменений. Параметры не набираются по одному через `--addfx` и `--set`.
  - `--copy` вставляет звенья целиком из трека шаблона и даёт им новые FXID. Если цепочка трека была выключена (`FX 0`), включает её.
  - `--bypass` выключает звено, не удаляя его.
  - `--drop` удаляет трек. Если трек закрывал папку, глубину `ISBUS` получает предыдущий. Папку с детьми скрипт не удаляет.
  - `--header` копирует строки шапки из шаблона (`TIMELOCKMODE`, `SAMPLERATE`, `RENDER_PATTERN`, `RENDER_FMT`).
  - Проверяет, что блоки сходятся и у каждого JSFX 64 токена. Тесты: `tests/test_chain.py`, 6 штук.
- **Проверочный рендер без правки оригинала**: копия заливается в папку песни как `zz-check.rpp`, открывается через мост и рендерится `render.sh --proj zz-check.rpp --set ...`. Дубли в старых проектах лежат рядом с `.rpp` (`RECORD_PATH ""`), поэтому относительные пути работают.
- Модель с перенесённой цепочкой предсказала −13.0 LUFS, рендер дал −13.0. При потолке лимитера −1.4 true peak вышел −0.7 dBTP. Потолок −1.8 с порогом −7.6 (подъём тот же, 5.8 dB) дал −1.1 dBTP при той же громкости.

## Скилл `reaper-song`: запись на Zoom H2e

Источник - «TopUp - Чтобы любить - h2e» (21.06.2025). В проекте не было айтемов, рядом лежали `250621_215608_FRONT_RAW.WAV` и `_REAR_RAW.WAV`, оба 96 кГц, 32 bit float, 5:28. В файле два дубля: первый оборван на 1:55, второй с 2:35 до конца, 2:53.

- **Файлы H2e - сырые капсулы, а не стерео.** Правый канал FRONT и правый канал REAR совпадают побитово (корреляция 1.0, сдвиг 0): это общая боковая капсула. Левые каналы - центральные капсулы. Тыловая громче фронтальной на 5 dB, исполнитель сидел сзади. Пользователь выбрал на слух вариант `rear_ms` из четырёх превью.
- **`popstas/ms_decode.jsfx`** (новый, `scripts/`): L = M + w·S, R = M − w·S. Штатного декодера на nb нет, только кодер `utility/KanakaMSEncoder1`. Добавлен в модель (`ms_decode()` в `analyze.py`, `MODELED` в `freezelib.py`).
- **`analyze.py` ресемплирует источники не 48 кГц** (`resample_poly`). Раньше на 96 кГц стоял assert.
- **`chain.py`**: новые опции `--name`, `--item`, `--addjs`, чтобы собрать проект из пустого.
- Модель предсказала −13.0 LUFS, рендер дал −13.0, поправка 0, а не +0.5 по умолчанию: ReaVerb выключен.
- **Межсэмпловые пики самой записи**: true peak на 1.5 dB выше сэмплового ещё до отсечки. Сэмпловый клампинг `MGA_JSLimiterST` их только наращивает: потолок −1.8 / −2.5 / −3.2 дал −0.4 / −0.4 / −0.5 dBTP при −13.0 LUFS. Модельный WAV до MP3 даёт −0.3, значит, MP3 ни при чём. Решение - отдача без отсечки: −13.7 LUFS, −1.2 dBTP. У ReaLimit на мастере режима true peak среди параметров нет.
- Тесты: 55, все проходят (новые в `test_chain.py` и `test_ms_decode.py`).
- Наблюдение по ходу: закрытие вкладок через мост (`40860`) закрыло все вкладки, а не одну, и REAPER открыл окно сохранения. Пользователь нажал Cancel, файлы не пострадали. Вкладки через мост больше не закрывать, файл менять, когда вкладка не открыта.

## Скилл `reaper-song`: проект, который модель не считает, - сведение по стемам

Источник - «ЖЩ - 7000000000 (на экспорт)» (2019, popstas-pc). Гитары собраны из одного DI через `guitar/amp-model`, у баса `pitch/pitchdown`, два MT-PowerDrumKit идут посылами в `drums wav`, у второго голоса MUTEENV. Модель всё это пропускает: она дала мастер −1.1 LUFS (фейдер мастера −12.4 dB она тоже не учла). Рендер «до» дал −18.1.

- **`stembal.py`** (новый): громкость стемов по окнам 10 с и разница с опорным стемом. Нужен там, где `analyze.py` не годится, а стемы снимает `render.sh --stems`. Цикл: `apply.sh` на `zz-check.rpp`, потом `render.sh --stems --proj zz-check.rpp`, потом `stembal.py --ref <голос>`. Одна итерация ~1:50, до цели дошли за 4 рендера.
- **`chain.py`**: при проверке 64 токенов строка параметров разбирается с учётом кавычек (`shlex`). Строковый слайдер amp-model `"Dumble Overdrive Special - Tweed Deluxe.wav"` раньше считался за 5 токенов, и скрипт отказывал.
- **Сохранение dirty от MT-PowerDrumKit** (`temp_save_drumkit_dirty`): теперь принимает и undo «Close FX chain: Track N» для трека с MT-PowerDrumKit. Это след автоактивации, которую пользователь настроил 22.11. Просить активировать плагин больше не нужно, SKILL.md и сообщения `freeze.sh`/`calib.py` исправлены.
- Ограничение: у проекта в формате REAPER 5 после открытия в REAPER 7 чанки треков отличаются от файла форматом строк (`BUSCOMP`, `TRACKHEIGHT`, `MIDIOUT`). Поэтому `temp_save_drumkit_dirty` первое сохранение не делает. Сохранено вручную после сверки разницы.
- `fetch.sh` принимает `RENDER_FILE` за путь к медиа (`нет файла: D:/rec/2019`) и создаёт локальную папку `D:`. Это безвредно, но не исправлено.
