# 2026-11-23

## Скилл `reaper-song`: порядок для песни без VST

Источник - «Екатерина Яшникова - Белая Птица», записана 23.11 по шаблону, без VST.

- **Рендер «до» со стемами - до подбора вариантов, и без VST тоже.** Варианты сначала подбирались без поправки (мастер +0.5 по умолчанию). Рендер «до» дал поправку mic +0.6, guitar +0.4, и баланс выбранного варианта сместился с 5.9 на 6.1 LU: makeup голоса подбирали второй раз. Порядок «рендер `--stems --calib` → варианты» раньше был записан только для песен с VST, теперь и для остальных.
- **Пример настройки голоса.** Шаблон −8/+5, медиана 0.7 → айтем −0.9, трим −4, makeup +4.5, лимитер −8.8. Формула трима дала −4.5, на деле подошло −4. Медиана 2.1, баланс по 20 с +1.9…+4.5 → +2.9…+5.6. Рендер −13.0 LUFS / −1.2 dBTP совпал с моделью.
